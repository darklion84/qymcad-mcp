## doc_new

Start a new document with one empty part (replaces the open document; save it first if needed).

```json
{
  "additionalProperties": false,
  "type": "object"
}
```

## doc_open

Open a .qcad file written by QymCAD of the same release (or by this server). Rebuilds what has no stored geometry.

```json
{
  "additionalProperties": false,
  "properties": {
    "path": {
      "description": "Path to a `.qcad` file.",
      "type": "string"
    }
  },
  "required": [
    "path"
  ],
  "type": "object"
}
```

## param_set

Create or change a named parameter and rebuild everything that depends on it. Use parameters for every dimension the user may want to change, then refer to them in expressions. If the model no longer builds, the change is rolled back and the error returned.

```json
{
  "$defs": {
    "Num": {
      "anyOf": [
        {
          "format": "double",
          "type": "number"
        },
        {
          "type": "string"
        }
      ],
      "description": "A dimension: either a plain number (millimetres or degrees) or an expression over parameters, e.g. `\"w/2\"`,\n`\"t+1\"`, `\"2*pi*r\"`. Expressions keep the model parametric: changing the parameter later rebuilds the part."
    }
  },
  "additionalProperties": false,
  "properties": {
    "name": {
      "description": "Parameter name: letters, digits, `_`, starting with a letter. Stored lowercase.",
      "type": "string"
    },
    "value": {
      "$ref": "#/$defs/Num",
      "description": "A number, or an expression over other parameters (`\"w/2\"`, `\"2*t+1\"`)."
    }
  },
  "required": [
    "name",
    "value"
  ],
  "type": "object"
}
```

## fillet

Round edges of a body. `edges` is a selection: ids from topology, or a description such as {"edges_of": {"facing": "+z"}} (top outline) or {"along": "z"} (vertical edges). The edges are stored by their persistent names, which QymCAD carries across upstream edits. A radius too big for the geometry is an error and nothing changes. Returns the new body id (the part's current body from now on); face/edge ids read from earlier bodies are stale — call topology again before picking more.

```json
{
  "$defs": {
    "Num": {
      "anyOf": [
        {
          "format": "double",
          "type": "number"
        },
        {
          "type": "string"
        }
      ],
      "description": "A dimension: either a plain number (millimetres or degrees) or an expression over parameters, e.g. `\"w/2\"`,\n`\"t+1\"`, `\"2*pi*r\"`. Expressions keep the model parametric: changing the parameter later rebuilds the part."
    },
    "ObjRef": {
      "anyOf": [
        {
          "format": "uint64",
          "minimum": 0,
          "type": "integer"
        },
        {
          "type": "string"
        }
      ],
      "description": "An object reference: its numeric id, or the name given when it was created."
    }
  },
  "additionalProperties": false,
  "properties": {
    "body": {
      "anyOf": [
        {
          "$ref": "#/$defs/ObjRef"
        },
        {
          "type": "null"
        }
      ],
      "description": "Body id or name. Default: the part's current body."
    },
    "edges": {
      "anyOf": [
        {
          "items": {
            "minimum": 0,
            "type": "integer"

          "type": "array"
        },
        {
          "minimum": 0,

    },
    "name": {
      "default": null,
      "description": "Name for the new feature (timeline node), usable instead of its id later. Default: QymCAD's generic name.",
      "type": [
        "string",
        "null"
      ]
    },
    "radius": {
```

```json
      "anyOf": [
        {
          "format": "double",
          "type": "number"
        },
        {
          "type": "string"
```
