## doc_new

Start a new document with one empty part (replaces the open document; save it first if needed).

```json
{
  "additionalProperties": false,
  "type": "object"
}
```

## doc_open

Open a .qcad file written by QymCAD of the same release (or by this server). Rebuilds what has no stored geometry.

```json
{
  "additionalProperties": false,
  "properties": {
    "path": {
      "description": "Path to a `.qcad` file.",
      "type": "string"
    }
  },
  "required": [
    "path"
  ],
  "type": "object"
}
```

## param_set

Create or change a named parameter and rebuild everything that depends on it. Use parameters for every dimension the user may want to change, then refer to them in expressions. If the model no longer builds, the change is rolled back and the error returned.

```json
{
  "$defs": {
    "Num": {
      "anyOf": [
        {
          "format": "double",
          "type": "number"
        },
        {
          "type": "string"
        }
      ],
      "description": "A dimension: either a plain number (millimetres or degrees) or an expression over parameters, e.g. `\"w/2\"`,\n`\"t+1\"`, `\"2*pi*r\"`. Expressions keep the model parametric: changing the parameter later rebuilds the part."
    }
  },
  "additionalProperties": false,
  "properties": {
    "name": {
      "description": "Parameter name: letters, digits, `_`, starting with a letter. Stored lowercase.",
      "type": "string"
    },
    "value": {
      "$ref": "#/$defs/Num",
      "description": "A number, or an expression over other parameters (`\"w/2\"`, `\"2*t+1\"`)."
    }
  },
  "required": [
    "name",
    "value"
  ],
  "type": "object"
}
```

## sketch_create

```json

    "BaseName": {
      "enum": [
        "XY",
        "XZ",
        "YZ"
      ],
      "type": "string"

    "ObjRef": {
      "anyOf": [
        {
          "format": "uint64",
          "minimum": 0,
          "type": "integer"
        },
        {
          "type": "string"
        }
      ],
      "description": "An object reference: its numeric id, or the name given when it was created."
    },
    "PlaneArg": {
      "anyOf": [
        {
          "$ref": "#/$defs/BaseName"
        },
        {
          "properties": {
            "plane": {
              "$ref": "#/$defs/ObjRef"
            }
          },
          "required": [
            "plane"
          ],
          "type": "object"
        },
        {
          "properties": {
            "body": {
              "$ref": "#/$defs/ObjRef"
            },
            "face": {
              "format": "uint32",
              "minimum": 0,
              "type": "integer"

          },
          "required": [
            "body",
            "face"
          ],
          "type": "object"
        }
      ],
      "description": "A plane: `\"XY\"` (normal +Z), `\"XZ\"` (normal −Y), `\"YZ\"` (normal +X); `{\"plane\": <datum plane>}`; or\n`{\"body\": <body>, \"face\": <face id>}` for a planar face (face ids come from `topology`)."
```

## extrude

Extrude sketch contours: add material (the first add creates the part's body), cut, intersect, or a new body. Atomic: if the feature does not build, nothing changes and the error is returned. Returns the new body id and the result bodies (volume, bbox).

```json
        {
          "const": "normal",
          "description": "Along the normal.",
          "type": "string"
        },
        {
          "const": "reverse",
          "description": "Against the normal (e.g. a pocket cut down from a top plane or face).",
          "type": "string"
        },
        {
          "const": "symmetric",
          "description": "Half to each side.",
          "type": "string"
        }
      ]
    },
    "Num": {
      "anyOf": [
        {
          "format": "double",
          "type": "number"
        },
        {
          "type": "string"
        }
      ],
      "description": "A dimension: either a plain number (millimetres or degrees) or an expression over parameters, e.g. `\"w/2\"`,\n`\"t+1\"`, `\"2*pi*r\"`. Expressions keep the model parametric: changing the parameter later rebuilds the part."
    },
    "ObjRef": {
      "anyOf": [
        {
          "format": "uint64",

        {
```
