## doc_new

Start a new document with one empty part (replaces the open document; save it first if needed).

```json
{
  "additionalProperties": false,
  "type": "object"
}
```

## doc_open

Open a .qcad file written by QymCAD of the same release (or by this server). Rebuilds what has no stored geometry. Both doc.bodies and rebuild.bodies report the geometry after opening and rebuilding; stored-file metrics appear only in stored-versus-rebuilt mismatch warnings. Stored forward-timeline projections are refused. Stored cross-part projections are accepted with a rebuild warning per projection identifying sketch, source body and owner parts: projected in the source part's local coordinates; its placement is ignored, as in the QymCAD app. sketch_info marks their entities cross_part:true.

```json
{
  "additionalProperties": false,
  "properties": {
    "path": {
      "description": "Path to a `.qcad` file.",
      "type": "string"
    }
  },
  "required": [
    "path"
  ],
  "type": "object"
}
```

## doc_save

Save the document as .qcad; the directory must exist. An explicit path permits replacing an existing model; the result reports replaced=true when the target existed before saving (false for a fresh path). A pathless save requires the first solid feature of the last loaded/saved model to remain; after undo/delete replaces that model, give a path or overwrite=true. Normal edits keep the association. doc_new needs an explicit path. Refuses to overwrite a file containing bodies when this document has no bodies, unless allow_empty=true; that explicit empty replacement also resets the association. Open it in the QymCAD app with File > Open; double-click does not work on macOS.

```json
{
  "additionalProperties": false,
  "properties": {
    "allow_empty": {
      "default": false,
      "description": "Permit an empty document to overwrite an existing .qcad containing bodies. Default false.",
      "type": "boolean"
    },
    "overwrite": {
      "default": false,

    "path": {
      "default": null,
      "description": "Where to write the `.qcad`. Default: the file the document came from or was last saved to.",
      "type": [
        "string",
        "null"
      ]
    }
  },
  "type": "object"
}
```

## doc_info

The whole document: parameters, sketches (world_frame, contours, degrees of freedom), the timeline, result bodies (volume_mm3 at native floating-point precision, bbox), errors and warnings. JSON bbox and sketch world_frame coordinates/directions use 4 decimal places for presentation (internal geometry, parameters, and input-ready dimensions retain full precision), rounded half away from zero; negative zero is normalized to zero. Bboxes use fresh tessellation with 0.005 mm nominal deflection (larger bodies over 500 mm diagonal use 1e-5 of the diagonal) plus f32 coordinate rounding, including after doc_open and rebuild; they approximate extrema and may slightly under-bound curves or over-bound after decimal rounding (native padded bounds are a fallback if meshing fails). Use volume_mm3 for size checks and topology face positions for placement.

```json
{
  "additionalProperties": false,
  "type": "object"
}
```

## dimension_set

Set a native sketch, feature or sketch-item driving dimension's value/formula and/or name. Names make dimensions available to other formulas; doc_info lists them. Chamfer dist/d2 metadata reports mode and unit; d2 is degrees in dist_angle, mm in two_dist, and refused in symmetric. Move accepts only dx/dy/dz, the total affine translation including rotation pivot correction; rotation angle/pivot have no drivers. Refuses unknown or ambiguous targets, name collisions, cycles, bad formulas and unsolved edits atomically. An empty name removes the name. New sketch-item names are refused because native app SetDriver leaves their solids stale. Text height edits and changes to existing text through imported formulas are refused: remove and recreate text to change its height, position, angle, font or characters. Item edits that conflict with driving sketch constraints are refused; edit the sketch constraint instead.

## param_set

Create or change a named parameter and rebuild everything that depends on it. Use parameters for every dimension the user may want to change, then refer to them in expressions. If the model no longer builds, the change is rolled back and the error returned. Edits that change existing text geometry through imported item formulas are refused; remove and recreate the text instead. After GUI structural edits (re-hosting a datum sketch, creating a new datum sketch, or replacing a datum distance/angle formula or driver name), reopen and save through the server before further GUI parameter edits so its persisted datum dependencies are refreshed (ADR 0007).

## sketch_create

Create an empty sketch on a plane: "XY", "XZ", "YZ", {"plane": <datum plane>} or {"body": <body>, "face": <face id>}. A face sketch's origin is the world origin projected onto the face plane (in the owning component's local coordinates, then carried by its placement). Its x/y directions are positive coordinate axes of that component in right-handed order: +Z: +X/+Y, -Z: +Y/+X, +X: +Y/+Z, -X: +Z/+Y, +Y: +Z/+X, -Y: +X/+Z. For tilted faces x = normalize(+Z cross normal), y = normal cross x. Read sketch_info.world_frame for the resolved world axes. Returns its id.

## sketch_add

Add entities to a sketch (all or nothing): point, rect, circle, circle_tangent, line, polyline, spline, arc, ellipse, ellipse_arc, polygon, slot, text. Text uses fixed numeric height, at and angle; remove and recreate it to change height, placement, angle, font or characters because edits can swap glyph/counter contour ids. Text height edits through dimension_set and indirect parameter/item formulas are refused. Its default font is Arial face 0 at /System/Library/Fonts/Supplemental/Arial.ttf; missing fonts or non-whitespace characters without outline contours (including bitmap-only glyphs) are refused and listed. Spaces are allowed. Baked glyphs reopen without the font; retyping in the app needs its recorded path. Curves are fully dimensioned from the sketch origin with the given numbers/expressions, so it stays parametric and editable in QymCAD (`dimensioned: false` leaves point/line/polyline/spline/arc/ellipse/ellipse_arc/polygon/slot free for sketch_constrain). Ellipse/rectangle turn formulas must stay strictly between 0 and 180 degrees (literal 0/180 allowed); ellipse-arc eccentric endpoint angles must stay strictly between 0 and 180. Polygon sides accept integral formulas in 3..=64. Points that coincide with existing ones are joined (a polyline end and an arc end become one point). A point returns point:id and reused:true when coincident; reused points receive no new constraints. Native points add no contours or material; their x/y default to 0 and dimensioned defaults true. Closed shapes form contours; a contour inside another becomes a hole when the outer one is extruded. Returns the new entity and point ids and the sketch (entities, points, constraints, contours, dof; dof [0, 0] = fully defined). Features built from the sketch are rebuilt.

## sketch_constrain

Add a geometric constraint or a driving dimension between existing points/entities of a sketch (ids from sketch_info, or "origin", "x_axis", "y_axis"). Origin/frame/axis points are materialized only when geometry or constraints need them, usually after the first sketch_add; named aliases materialize their reference points. Use it to dimension geometry added with `dimensioned: false`, or to relate entities (tangent, equal, symmetric, ...). Refused, with nothing changed, when it would over-constrain the sketch (the message names the constraints it duplicates or contradicts; remove one with sketch_remove, or add a dimension as `reference: true`) or cannot be solved. A geometric constraint that already holds and is implied returns index null. Returns the constraint index, dof and the sketch; features built from the sketch are rebuilt.

## hole

Drill holes by planar `face` or `sketch` (exactly one): plain, counterbore or countersink; blind (`depth`) or `through`. Sketch placement supports world/fixed datum frames and stock-lineage face hosts; parameterized/named datum, projected marker or independent face support is refused. The entire transitive named-expression source graph must be free of reference (non-driving) measurements, including earlier source sketches, the marker itself, aliases and named Point formulas; refusal names the measurement. Global parameters, driving dimensions and named driving Point coordinates stay allowed; driving sources do not require sketch-array ordering. Uses every isolated point along the negative sketch normal (`flip` reverses). Optional `points` must list ALL eligible ids exactly once; native subsets are unsupported. Every requested point must retain a nonzero bore face or the call refuses atomically, naming the missing point. `at`/`offset` are face-only; `points`/`flip` are sketch-only. Sketch holes refuse off_u/off_v dimension edits. For inward corners, including a boss/plate curved junction, pass edges: {"concave": true}; combine with {"and": [{"concave": true}, {"along": "y"}]}. Uncertain shallow signs or disagreement among five arc-length samples are omitted. Bare corner filters and positive `and` selections count only uncertain edges matching the other conditions; an `and` requiring both concave and convex matches no edge and reports no omission. ## batch

Run 1..=200 predictable modelling operations in order with one undo entry and all-or-nothing rollback. Use batch for known parameters, sketches and features referenced by name/id; use single calls when you need topology ids, sketch_info, select or a render between operations. Only param_set, dimension_set, param_delete, sketch_create, sketch_add, sketch_project, sketch_constrain, sketch_remove, sketch_edit, plane_offset, extrude, revolve, sweep, loft, fillet, chamfer, hole, shell, push_face, linear_array, circular_array, move, mirror, thread, body_boolean, split, import and feature_delete are allowed. Every step's args are validated with that tool's standalone argument struct and JSON-string leniency before anything runs. Each handler keeps its normal rebuild/checks. Errors identify the 1-based step and tool; nothing was changed. Compact results contain step/tool and created node id/name when applicable, final bodies/warnings/errors; verbose=true adds each step's full normal JSON result as result. Undo reports batch and Batch (N steps); counts as one of 16 retained calls.
